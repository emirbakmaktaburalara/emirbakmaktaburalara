I work on how teams collect, report and forward their data: web, mobile and backend events, unified reports and destinations, with consent and privacy built in.

**Tracking:** Google Tag Manager and server-side GTM, Meta CAPI, TikTok Events API

**Privacy:** Consent management, GDPR and KVKK

**Mobile:** SKAdNetwork, ATT, MMPs
